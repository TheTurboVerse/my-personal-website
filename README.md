## 🧠 Development Process & AI Assistance

I built this website as a learning project, experimenting with the design and improving it as I went.

During development, I explored different navigation ideas, including floating navigation bars and a back-to-top control. I eventually decided against keeping those features and chose a floating hamburger menu instead.

I used a checkbox-based approach to implement the menu with CSS. AI helped me explore that implementation, write and understand parts of the code, identify mistakes, debug issues, and understand how concepts such as responsive styling with `@media` queries work.

I also used AI to explore colour palette options and understand how different colours could work together with the website's visual style. I used these suggestions as part of my learning and decision-making process.

The goal wasn't just to make the website work. It was to understand what I was building, experiment with different approaches, figure out what wasn't working, and improve the result step by step.

This project represents my learning process, including the ideas I changed, the features I removed, the bugs I encountered, and the things I learned along the way.
